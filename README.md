# lernen

Mein Lern-Workspace für den Skill `/teach`.

## Benutzen

1. Auf claude.ai/code (oder in der Claude-App) eine neue Cloud-Sitzung mit diesem Repository starten.
2. `/teach <Thema>` eingeben.
3. Claude legt hier `MISSION.md`, `lessons/`, `learning-records/`, `reference/` usw. an und pusht sie.
