# Lernen

Mein Lern-Workspace für den Skill `/teach`, ein Ordner pro Fach.

## Benutzen

1. **Unterlagen hochladen** in den Ordner [`eingang/`](eingang/)
   (auf github.com: „Add file“ → „Upload files“).
2. Auf claude.ai/code oder in der Claude-App eine neue Claude-Code-Sitzung
   mit diesem Repository starten.
3. `/teach <Fach>` eingeben, z. B. `/teach Statistik`.

Claude sortiert die Unterlagen ins Fach, fragt nach deinem Ziel, erstellt den
Stoffplan und speichert den Lernstand hier im Repository. Die Lernregeln
stehen in [`NOTES.md`](NOTES.md).
