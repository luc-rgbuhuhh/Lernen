# Unterlagen

Hier kommen deine Kursunterlagen hinein: Skript, Folien, Übungen, Altklausuren, Notizen.
PDFs funktionieren am besten. Dateinamen am besten sprechend, z. B. `skript-kapitel-3.pdf`
oder `altklausur-ws2024.pdf`.

Hochladen auf dem iPad: auf github.com im Repository diesen Ordner öffnen,
„Add file“ → „Upload files“.
