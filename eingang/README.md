# Eingang

Hier lädst du neue Unterlagen hoch: Skript, Folien, Übungen, Altklausuren, Notizen.
Am besten als PDF und mit sprechendem Namen, z. B. `statistik-skript.pdf` oder
`statistik-altklausur-ws2024.pdf`. Dann ist auch klar, zu welchem Fach sie gehören.

**Hochladen auf dem iPad:** auf github.com im Repository diesen Ordner öffnen,
„Add file“ → „Upload files“ → Dateien auswählen → „Commit changes“.

Beim nächsten `/teach <Fach>` verschiebt Claude die Dateien nach
`faecher/<fach>/unterlagen/`.
